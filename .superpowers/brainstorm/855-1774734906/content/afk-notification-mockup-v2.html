Feature 1: Improved AFK Notification Flow

0:00 — Watch starts
AFK timer begins (28 min). Watch timer shown above Watch button as 00:00:00.
28:00 — AFK Warning
Discord ping sent. App window flashes. Taskbar flashes. In-app message: "Move character to prevent AFK logout" + Reset AFK Timer button. Watch timer turns orange and blinks (PAUSED).
30:00 — Auto-logout Warning (if no reset)
Second Discord message: "Your character has most likely auto-logged out. Return to PC." AFK timer dies. Flashing continues. Watch timer stays paused.
Resolution — one of:
• Reset clicked → message dismissed, timer restarts 28 min, watch timer resumes
• Queue pop detected → everything stops, normal pop notification
• Stop Watch clicked → everything stops, session ends
