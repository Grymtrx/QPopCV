# AFK Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an AFK tab with a checkbox that sends a Discord @mention after 28 minutes of continuous watch time to prevent Blizzard auto-logout.

**Architecture:** A `threading.Timer` is armed in `Api.start_watch()` when `afk_notify=True` and cancelled in `stop_watch()`. The timer fires `_send_afk_notification()` which POSTs directly to the Discord webhook. The checkbox state flows through config like all other settings.

**Tech Stack:** Python `threading.Timer`, `requests.post`, HTML checkbox, CSS `accent-color`, vanilla JS DOM wiring.

class TestAfkTimer:

        MockTimer.assert_called_once_with(28 * 60, api._send_afk_notification)

    @patch("qpopcv.api.QPopWatcher")
    @patch("threading.Timer")
    def test_timer_not_created_when_afk_notify_false(self, MockTimer, MockWatcher):

        self._start(api, False, MockWatcher)

    @patch("qpopcv.api.QPopWatcher")

    def test_stop_watch_without_timer_does_not_raise(self):

def stop_watch(self) -> dict:
    if self._watcher:
        self._watcher.stop()

    if self._afk_timer:

        self._afk_timer = None

```python
def _send_afk_notification(self) -> None:
    """Called by threading.Timer after 28 minutes of watching."""
    webhook_url = str(self.config.get("webhook_url", "")).strip()
    user_id = str(self.config.get("user_id", "")).strip()
    if not webhook_url or not user_id:
        return
    content = (
        f"<@{user_id}> Watch time nearing 30 minutes. "
        "Return to PC & move character to prevent blizzard auto-logout."
    )
    try:
        requests.post(webhook_url, json={"content": content}, timeout=5)
    except Exception as exc:
        logger.error("AFK notification failed: %s", exc)
    self._afk_timer = None
```
