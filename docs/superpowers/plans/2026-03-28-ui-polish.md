```javascript

  stopWatchTimer();

  watchBtn.classList.remove('is-watching');
```

## Task 3: Always on Top + 50% Opacity When Unfocused

**Files:**
- Modify: `qpopcv/app_ui.py`

PyQt6 handles window activation natively via `changeEvent`. We introduce a `_MainWindow(QMainWindow)` subclass so we can override `changeEvent` cleanly without monkey-patching.

- [ ] **Step 1: Add `_MainWindow` subclass to app_ui.py**

After the `_Bridge` class definition (around line 207), add:

First, add `QEvent` to the existing top-level import in `app_ui.py`:

```python
from PyQt6.QtCore import QEvent, QObject, QUrl, Qt, pyqtSignal
```

Then add the subclass after the `_Bridge` class:

```python
class _MainWindow(QMainWindow):
    """QMainWindow subclass that stays on top and dims when unfocused."""

    def changeEvent(self, event):  # noqa: N802
        super().changeEvent(event)
        if event.type() == QEvent.Type.ActivationChange:
            self.setWindowOpacity(1.0 if self.isActiveWindow() else 0.5)
```

- [ ] **Step 2: Replace `QMainWindow()` with `_MainWindow()` and add always-on-top flag**

In the `run()` method, find:

```python
        self._window = QMainWindow()
        self._window.setWindowTitle("QPopCV")
        self._window.setWindowFlags(
            Qt.WindowType.FramelessWindowHint | Qt.WindowType.Window
        )
```

Replace with:

```python
        self._window = _MainWindow()
        self._window.setWindowTitle("QPopCV")
        self._window.setWindowFlags(
            Qt.WindowType.FramelessWindowHint
            | Qt.WindowType.Window
            | Qt.WindowType.WindowStaysOnTopHint
        )
```

- [ ] **Step 3: Verify manually**

Run `py main.py`. Confirm:

- Clicking away dims the window to ~50% opacity
- Clicking back on the window restores full opacity
