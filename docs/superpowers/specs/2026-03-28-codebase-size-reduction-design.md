# Codebase Size Reduction & Repo Cleanup

**Date:** 2026-03-28
**Version target:** 1.2.4

## Goal

Reduce the git repo size, clean up unused files, shrink the built executable ZIP, reorganize the repo structure, and document expected file sizes in the build workflow.

## Scope

### 1. Remove build artifacts from git tracking

The `qpopcv/_internal/` directory (170 MB, 982 files) is PyInstaller output that was accidentally committed. It should never be in the repo.

**Actions:**
- Add `qpopcv/_internal/` and `*.exe` (inside qpopcv/) to `.gitignore`
- `git rm -r --cached qpopcv/_internal/`
- The local copy stays (won't break anything), git just stops tracking it

### 2. Remove unused tracked files

| File | Size | Reason |
|------|------|--------|
| `qpopcv/theme.py` | ~2 KB | Deprecated CustomTkinter artifact, zero imports |
| `qpopcv/media/icon/icon.ico` | 219 KB | Old icon, replaced by `icon_v2.ico` |
| `qpopcv/media/v1.1.0.png` | 28 KB | Screenshot not referenced anywhere |
| `q.png` (root) | 20 KB | Not referenced in any code or docs |
| `expirements/` | ~60 KB | Old HTML UI prototypes (also misspelled) |

**Keep:**
- `tools/` — dev utilities, small, potentially useful
- `conftest.py` — actively used by tests
- `MobileNoti.png` — referenced in README.md

### 3. Clean up conftest.py

Remove the `_stub_customtkinter()` function and its call — CustomTkinter was removed in v1.0.24.

### 4. Add PyInstaller excludes to .spec

Add an `excludes` list to `QPopCV.spec` to prevent bundling unused stdlib/third-party modules:

```python
excludes=[
    'tkinter', '_tkinter', 'tcl', 'tk',
    'unittest', 'pydoc', 'doctest',
    'xml', 'xmlrpc',
    'sqlite3',
    'multiprocessing',
],
```

Estimated savings: ~5-10 MB from the built exe folder.

### 5. Delete local build artifacts (~1.7 GB)

Delete regenerable files from the local filesystem:

| Path | Size | Why safe |
|------|------|----------|
| `dist/` | 1.5 GB | Old ZIPs + build output — regenerated by `build.ps1`, available on GitHub releases |
| `qpopcv/_internal/` | 170 MB | PyInstaller runtime — regenerated every build |
| `build/` | 26 MB | PyInstaller temp — regenerated every build |
| `qpopcv/QPopCV.exe` | ~8 MB | Built exe in wrong location (real one goes to `dist/`) |
| `__pycache__/`, `.pytest_cache/`, `qpopcv/__pycache__/`, `tests/__pycache__/` | ~35 KB | Auto-regenerated caches |

**Do NOT delete:** `.venv/`, `qpopcv/config.local.json`, `qpopcv/metrics.json`, `QPopCV.spec`

### 6. Update .gitignore

Add entries for artifacts that shouldn't be tracked:
- `qpopcv/_internal/`
- `qpopcv/*.exe`
- `qpopcv/*.log`
- `qpopcv/metrics.json` (already listed at top level, but be explicit)

### 7. Update build-release skill with file size info

Add expected file size ranges to the skill and `RELEASE.md` so builders know what to expect and can catch regressions:

```
Expected sizes (v1.2.x):
  dist\QPopCV\          ~XXX MB (uncompressed)
  dist\QPopCV-vX.Y.Z.zip  ~XXX MB
```

(Actual values to be measured after the cleanup build.)

### 8. Bump version

`APP_VERSION` → `"1.2.4"` per versioning rules.

## Out of scope

- OpenCV dependency (staying as-is per user request)
- Git history rewriting (BFG/filter-branch) — can be done later if desired
- UI stack replacement (PyQt6 WebEngine stays)

## Risk

Low. All changes are additive (gitignore, excludes) or removing confirmed-unused files. Tests will be run to verify nothing breaks.

## Expected outcome

- Git repo: ~170 MB smaller on fresh clone
- Built ZIP: ~5-10 MB smaller (from spec excludes)
- Local disk: ~1.7 GB reclaimed from build artifacts
- Cleaner file tree with no stale artifacts
